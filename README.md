# BER Site Survey

An offline survey tool for BER assessments. It captures the inputs DEAP needs on site (dwelling details, building, ventilation, space heating, water heating and renewables) and produces a desk report to key into DEAP.

## Install on iPad or iPhone

1. Open the site address in Safari.
2. Tap Share, then Add to Home Screen.
3. Open it once from the icon while you have signal. After that it works with no signal.

Surveys are saved only on the device they were entered on. Use the Backup tab to copy a survey to another device.
